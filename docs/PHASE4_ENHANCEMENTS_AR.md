# المرحلة الرابعة - تحسينات البوابة، التعريب، وCI/CD

## ما تم إنجازه
- تحسين بوابة المواطن `/my-cases` بإمكانيات البحث والتصفية
- إضافة صفحة خط زمني للحالة `/case-timeline`
- إتاحة إرسال ملاحظة من المواطن المسجل عبر الصفحة الجديدة
- إضافة API لعرض الخط الزمني للحالة
- إضافة ملف ترجمة عربي مبدئي `translations/ar.csv`
- إضافة Dockerfile تطبيقي وملف docker-compose.example
- إضافة GitHub Actions workflow للتحقق من Python وJSON
- إضافة اختبار مبدئي للـ portal API

## المسارات الجديدة
- `/case-timeline?case_id=...`
- `/case-timeline/` عبر المجلد المتوافق

## ملاحظات
- ملف الترجمة الحالي هو بداية جيدة ويمكن توسيعه لاحقاً عبر `bench generate-pot-file` وملفات CSV إضافية.
- ملفات Docker الحالية موجهة كمرجع لتغليف التطبيق داخل بيئة Bench وليست بديلاً كاملاً عن بنية Frappe متعددة الخدمات.
