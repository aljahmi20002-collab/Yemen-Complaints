# المرحلة الخامسة - الضبط التشغيلي والقنوات المتعددة

## ما تم إنجازه
- إضافة **Complaint Notification Settings** كإعداد مركزي لإدارة البريد وSMS وWhatsApp
- بناء طبقة `messaging.py` لتوحيد الإرسال متعدد القنوات
- تشديد قواعد الانتقال بين حالات الشكاوى حسب الدور التشغيلي
- فرض وجود `Resolution Summary` قبل الحسم أو الإغلاق
- تحسين صلاحيات المستشار لرؤية الحالات الجديدة وغير المسندة لتمكين الفرز الأولي
- توسيع API للخط الزمني بحيث يدعم عرض الإحالات للطاقم الداخلي
- إضافة `get_case_activity_feed` لاستخدامه مستقبلاً في شاشات التدقيق والمراقبة
- إضافة اختبارات إضافية لحماية الانتقالات ومنع المواطن من تغيير الحالة مباشرة
- توسيع اللوحات بمؤشرات للتظلمات والتوزيع حسب الدولة والنوع

## الإعدادات الجديدة
### Complaint Notification Settings
توفر حقولاً لإدارة:
- تفعيل البريد الإلكتروني
- تفعيل SMS
- تفعيل WhatsApp
- تحديد رمز الدولة الافتراضي
- السماح بإشعارات المواطن أو الموظفين عبر القنوات الإضافية
- روابط المزود ومفاتيح التوثيق والمهل الزمنية

## ملاحظات تقنية
- تكامل SMS/WhatsApp الحالي **Generic HTTP Integration** ويمكن ربطه بأي مزود عبر endpoint يقبل JSON.
- عند عدم إعداد endpoint سيتم تجاهل القناة دون كسر التطبيق.
- البريد الإلكتروني يبقى القناة الأساسية افتراضياً.
