# UAT Checklist — منصة اليمن للشكاوى والتظلمات

## الهدف
قائمة اختبار قبول المستخدم النهائي (UAT) للتأكد من جاهزية النظام قبل الإطلاق الإنتاجي.

---

## 1) اختبار المواطن Citizen

### 1.1 الصفحة الرئيسية
- [ ] فتح الصفحة الرئيسية بنجاح.
- [ ] ظهور الشعار والخط الرسمي بشكل صحيح.
- [ ] عمل الروابط الرئيسية:
  - [ ] تقديم شكوى
  - [ ] تقديم تظلم
  - [ ] التحقق من الهوية
  - [ ] تتبع شكوى
  - [ ] طلباتي

### 1.2 تقديم شكوى
- [ ] فتح `/submit-complaint` بنجاح.
- [ ] ظهور المحافظات والمديريات اليمنية.
- [ ] فلترة المديريات حسب المحافظة.
- [ ] التحقق من الحقول الإلزامية.
- [ ] إرفاق ملف إن لزم.
- [ ] عدم السماح بالإرسال بدون OTP.
- [ ] إنشاء شكوى ناجحة بعد التحقق.
- [ ] ظهور رقم الحالة بعد الإرسال.

### 1.3 تقديم تظلم
- [ ] فتح `/submit-appeal` بنجاح.
- [ ] التحقق من المرجع السابق وسبب التظلم.
- [ ] عدم السماح بالإرسال بدون OTP.
- [ ] إنشاء تظلم ناجح بعد التحقق.

### 1.4 OTP Verification
- [ ] التحقق عبر Email.
- [ ] التحقق عبر SMS إذا كان المزود مفعلاً.
- [ ] التحقق عبر WhatsApp إذا كان المزود مفعلاً.
- [ ] التحقق عبر Telegram إذا كان المزود مفعلاً.
- [ ] عداد إعادة الإرسال يعمل.
- [ ] لا يقبل الرمز الخاطئ.
- [ ] تنتهي صلاحية الرمز بعد المدة المحددة.
- [ ] لا يمكن إعادة استخدام رمز مستعمل.

### 1.5 بوابة المواطن
- [ ] تسجيل الدخول بنجاح.
- [ ] فتح `/my-cases`.
- [ ] ظهور الطلبات الخاصة بالمستخدم فقط.
- [ ] عمل البحث والفلترة.
- [ ] فتح الخط الزمني للحالة.
- [ ] إرسال ملاحظة من المواطن على الحالة.

### 1.6 التتبع العام
- [ ] فتح `/track-complaint`.
- [ ] نجاح التتبع باستخدام البريد.
- [ ] نجاح التتبع باستخدام الهاتف.
- [ ] رفض التتبع ببيانات خاطئة.

---

## 2) اختبار المستشار Advisor

### 2.1 الوصول والصلاحيات
- [ ] ظهور Workspace الخاصة بالمستشار.
- [ ] ظهور الداشبورد الداخلي.
- [ ] ظهور الحالات الجديدة وغير المصنفة حسب الصلاحيات.

### 2.2 إدارة الحالة
- [ ] فتح حالة جديدة.
- [ ] تغيير الحالة إلى Under Review.
- [ ] تشغيل Smart Intake Assistant.
- [ ] تطبيق التوصيات الذكية.
- [ ] تعديل التصنيف والجهة والأولوية.
- [ ] إسناد الحالة لموظف الجهة أو المتابع.

### 2.3 AI Tools
- [ ] ترجمة نص.
- [ ] تلخيص نص.
- [ ] إصلاح الإملاء والنحو.
- [ ] اقتراح رد.
- [ ] صياغة رسالة.
- [ ] تصنيف الموضوع.
- [ ] حفظ المخرجات في الحقول المستهدفة.

---

## 3) اختبار موظف الجهة Agency Officer
- [ ] ظهور Workspace الخاصة بموظف الجهة.
- [ ] ظهور الحالات المسندة له فقط.
- [ ] تغيير الحالة إلى In Progress.
- [ ] إضافة تحديث داخلي.
- [ ] إضافة تحديث عام للمواطن.
- [ ] نقل الحالة إلى Waiting Citizen.
- [ ] إضافة Resolution Summary.
