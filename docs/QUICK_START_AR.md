# دليل البدء السريع

## 1) تثبيت التطبيق
```bash
bench --site your-site install-app yemen_complaints
bench --site your-site migrate
bench build
```

## 2) إعدادات أولية
- افتح `Complaint Notification Settings`
- فعّل البريد أو SMS أو WhatsApp أو Telegram حسب الحاجة
- افتح `Complaint AI Settings`
- أضف مفاتيح المزود إذا أردت AI

## 3) روابط مهمة
- `/submit-complaint`
- `/submit-appeal`
- `/track-complaint`
- `/my-cases`
- `/case-timeline`
- `/verify-identity`

## 4) أدوار مهمة
- Citizen
- Advisor
- Agency Officer
- Follow-up Officer
- Complaint System Manager
