# Production Review + Go-Live Checklist

## 1) التهيئة الأساسية
- [ ] تشغيل `bench --site your-site migrate`
- [ ] تشغيل `bench build`
- [ ] تفعيل `scheduler`
- [ ] التحقق من البريد الصادر Email Account
- [ ] ضبط النسخ الاحتياطي اليومي
- [ ] تفعيل HTTPS واسم النطاق النهائي

## 2) الأمان والهوية
- [ ] مراجعة صلاحيات الأدوار الخمسة
- [ ] تقييد صلاحيات Manager فقط للحسابات المصرح بها
- [ ] اختبار مسارات المواطن/المستشار/الموظف/المتابع
- [ ] تفعيل التحقق من هوية مقدم الشكوى عبر القنوات المطلوبة
- [ ] التحقق من انتهاء صلاحية رموز OTP وعدم إعادة استخدامها
- [ ] حماية مفاتيح API (AI / SMS / WhatsApp / Telegram)

## 3) الذكاء الاصطناعي
- [ ] تفعيل `Complaint AI Settings` بعد إدخال مفاتيح صحيحة فقط
- [ ] اختبار ChatGPT أو DeepSeek أو Gemini في بيئة staging أولاً
- [ ] مراجعة AI logs بانتظام
- [ ] وضع سياسة بشرية لمراجعة المخرجات قبل الاعتماد
- [ ] اختبار مساعد الاستقبال على 10-20 حالة متنوعة

## 4) التشغيل والإشعارات
- [ ] اختبار البريد للمواطن
- [ ] اختبار OTP عبر Email
- [ ] اختبار OTP عبر SMS/WhatsApp/Telegram إن تم تفعيلها
- [ ] اختبار إشعارات SLA
- [ ] اختبار التحديثات العامة للمواطن

## 5) جودة البيانات
- [ ] مراجعة المحافظات والمديريات بعد الترحيل
- [ ] مراجعة الجهات الحكومية والتصنيفات
- [ ] التحقق من صحة الطباعة والـ Workspaces والـ Web Forms

## 6) التوصيات النهائية
- استخدم staging قبل الإنتاج
- لا تفعّل AI للمستخدمين النهائيين دون ضوابط تكلفة ومراقبة
- راقب Error Log وBackground Jobs خلال أول أسبوع بعد الإطلاق
