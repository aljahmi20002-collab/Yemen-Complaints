# التحقق من هوية مقدم الشكوى قبل الإرسال

تمت إضافة طبقة تحقق من هوية مقدم الشكوى قبل إنشاء الشكوى أو التظلم عبر القنوات التالية:
- البريد الإلكتروني
- الرسائل القصيرة SMS
- WhatsApp
- Telegram

## كيف تعمل الآلية
1. يختار المواطن قناة التحقق داخل نموذج الشكوى أو التظلم.
2. يضغط على زر `إرسال الرمز`.
3. يرسل النظام رمز تحقق لمرة واحدة OTP إلى جهة الاتصال المختارة.
4. يدخل المواطن الرمز في واجهة التحقق.
5. عند نجاح التحقق، يسمح النظام بإرسال الشكوى.

## الإعدادات
تتم إدارة ذلك من خلال:
`Complaint Notification Settings`

### أهم الحقول
- `Enforce Identity Verification`
- `Allow Email Verification`
- `Allow SMS Verification`
- `Allow WhatsApp Verification`
- `Allow Telegram Verification`
- `Verification Code Length`
- `Verification Expiry (Minutes)`
- `Verification Resend Cooldown (Seconds)`
- `Verification Max Attempts`

## التخزين
يتم حفظ طلبات التحقق في Doctype:
`Complaint Identity Verification`

ويحفظ معلومات مثل:
- القناة
- جهة الاتصال
- حالة الطلب
- تاريخ الانتهاء
- عدد المحاولات
- هل تم استخدامه فعلاً مع شكوى ناجحة

## السلوك التشغيلي
- عند كون الشكوى مقدمة من بوابة المواطن أو Web Form يتم فرض التحقق قبل الحفظ.
- عند إنشاء الحالة من قبل موظف داخلي عبر Desk لا يتم فرض التحقق افتراضياً، إلا إذا كانت آلية العمل لديك تتطلب ذلك ويمكن توسيعها لاحقاً.

## ملاحظات
- Telegram هنا مبني كتكامل Generic Endpoint، ويمكن ربطه مع Bot/API داخلي حسب بيئتك.
- بعد نجاح إنشاء الشكوى، يتم تعليم طلب التحقق كـ `Used` حتى لا يعاد استخدامه.
