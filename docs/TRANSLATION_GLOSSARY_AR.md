# Translation Audit + Arabic UX Glossary

## الهدف
توحيد المصطلحات العربية المستخدمة في المنصة بحيث تكون واضحة، رسمية، ومتسقة بين الواجهات والتقارير والوثائق.

## المصطلحات المعتمدة
- Complaint Case = **ملف الشكوى / التظلم**
- Complaint Category = **تصنيف الشكوى**
- Government Entity = **جهة حكومية**
- Advisor = **المستشار**
- Agency Officer = **موظف الجهة**
- Follow-up Officer = **موظف المتابعة**
- Complaint System Manager = **مدير النظام**
- Identity Verification = **التحقق من الهوية**
- Security Event = **حدث أمني**
- AI Log = **سجل عمليات الذكاء الاصطناعي**
- Open Cases = **الحالات المفتوحة**
- Overdue Cases = **الحالات المتأخرة**
- Resolved Cases = **الحالات المحسومة**
- Waiting Citizen Cases = **حالات بانتظار المواطن**
- Executive Leadership Dashboard = **داشبورد القيادة العليا**
- Internal Operations Dashboard = **الداشبورد الداخلي للعمليات**
- Security Monitoring Dashboard = **داشبورد مراقبة الأمن والحماية**

## أسلوب الصياغة المعتمد
- الميل إلى لغة رسمية مبسطة.
- استخدام مصطلحات متسقة بين الوثائق والواجهات.
- تجنب الترجمة الحرفية غير الواضحة.
- استخدام "الحالة" عندما يكون المقصود workflow state.
- استخدام "ملف" عندما يكون المقصود complaint record ككل.

## ما تم عمله
- توسيع ملف `translations/ar.csv`
- تعبئة عدد كبير من المفردات الفارغة
- تحسين مفردات أساسية مرتبطة بالشكاوى والذكاء الاصطناعي والأمن والداشبوردات
