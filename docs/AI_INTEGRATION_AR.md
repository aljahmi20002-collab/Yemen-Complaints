# تكامل الذكاء الاصطناعي في منصة الشكاوى والتظلمات

## المزوّدات المدعومة
تمت إضافة دعم تكاملي قابل للتهيئة مع:
- ChatGPT / OpenAI
- DeepSeek
- Gemini

## الإعداد
من داخل النظام افتح:
`Complaint AI Settings`

ثم قم بما يلي:
1. فعّل `Enable AI`
2. اختر `Default Provider`
3. أدخل API Key للمزوّد المختار
4. راجع اسم النموذج `Model`
5. احفظ الإعدادات

## الأزرار الذكية المضافة
تمت إضافة Custom Buttons على الدوكتايبات النصية الرئيسية مثل:
- Complaint Case
- Government Entity
- Complaint Category

### الإجراءات المتاحة
- ترجمة نص
- تلخيص نص
- تحسين الكتابة
- إصلاح الإملاء والنحو
- تحليل نص
- اقترح رد
- صياغة رسالة
- تصنيف الموضوع
- ابحث عن عناصر النص
- اختصر
- اكتب بالتفصيل
- تبسيط اللغة
- اجعل النص رسمي
- خلاصة نص

## مساعد ذكي لمستشار استقبال الشكاوى
تمت إضافة زر:
`Smart Intake Assistant`

ويقوم بـ:
- تلخيص الحالة
- اقتراح التصنيف
- اقتراح الأولوية
- اقتراح الجهة
- استخراج العناصر المهمة
- إبراز مؤشرات الخطورة
- اقتراح الخطوات التالية
- اقتراح رد احترافي
- توليد رسالة مناسبة للمواطن

ويتم تخزين النتائج في حقول AI داخل `Complaint Case` لمراجعتها من قبل المستشار.

## ملاحظات مهمة
- لا يعمل الذكاء الاصطناعي إلا بعد تفعيل الإعدادات ووضع المفاتيح.
- جميع النتائج هي **مساعدات داعمة** وليست بديلاً عن القرار البشري.
- يوصى بمراجعة الناتج قبل اعتماده أو إرساله للمواطن.
