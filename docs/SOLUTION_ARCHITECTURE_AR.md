# الوثيقة المعمارية - منصة الشكاوى والتظلمات

## 1) الرؤية
منصة وطنية رقمية لاستقبال، فرز، إحالة، متابعة، وإغلاق الشكاوى والتظلمات للمواطنين اليمنيين داخل اليمن وخارجه، مع تتبع إلكتروني، لوحات تحكم، مؤشرات أداء، وتقارير تشغيلية وتنفيذية.

## 2) أصحاب المصلحة
- المواطن
- مكتب المستشار / المراجعة الأولية
- الجهة الحكومية المختصة
- المتابع / وحدة الرقابة والمتابعة
- مدير النظام

## 3) الأدوار والصلاحيات
### Citizen
- تقديم الشكاوى والتظلمات
- متابعة الحالة
- استلام التحديثات العامة

### Advisor
- الفرز الأولي
- تصنيف الحالة
- تحديد الجهة المعنية
- إعادة التوجيه أو طلب استكمال معلومات

### Agency Officer
- معالجة الحالة من داخل الجهة
- إدخال الردود والإجراءات
- رفع التوصية بالمعالجة أو الإغلاق

### Follow-up Officer
- مراقبة الالتزام بالمدد
- التصعيد للحالات المتأخرة
- المتابعة بين الأطراف

### Complaint System Manager
- إدارة البيانات المرجعية
- الإشراف الكامل على اللوحات والتقارير
- ضبط الأدوار وتهيئة التطبيق

## 4) المكونات الوظيفية
- استقبال الطلبات عبر Web Form
- إدارة ملفات الشكاوى والتظلمات
- التوجيه والإحالات
- التحديثات العامة والداخلية
- مؤشرات الأداء والتقارير
- الطباعة الرسمية
- التتبع الخارجي

## 5) نموذج البيانات الأساسي
- Complaint Case
- Complaint Assignment (child)
- Complaint Update (child)
- Government Entity
- Complaint Category

## 6) مؤشرات الأداء المقترحة
- عدد الحالات المفتوحة
- عدد الحالات المتأخرة
- نسبة الالتزام بـ SLA
- متوسط زمن الاستجابة الأولية
- متوسط زمن الإغلاق
- نسبة الحالات المغلقة خلال المدة
- معدل رضا المواطنين
- عبء العمل على الموظفين والجهات

## 7) التقارير المضمنة
- Complaint Summary
- SLA Breaches
- Officer Workload
- Citizen Satisfaction

## 8) اللوحات المضمنة
- Citizen Complaints Portal
- Advisor Complaint Desk
- Agency Officer Desk
- Follow-up Desk
- Yemen Complaints Manager Desk

## 9) التوسع المستقبلي المقترح
- Workflow رسمي عبر Frappe Workflow
- تكامل SMS / WhatsApp / Email Gateways
- OCR للمرفقات
- تصنيف ذكي للشكاوى بالذكاء الاصطناعي
- واجهة API لتكامل حكومي بين الجهات
