# منصة اليمن للشكاوى والتظلمات - Yemen Complaints

تطبيق مبني على **Frappe Framework** لاستقبال ومتابعة الشكاوى والتظلمات للمواطنين اليمنيين من أي مكان في العالم.

## الأهداف
- تمكين المواطن من رفع شكوى أو تظلم عبر Web Form احترافي.
- متابعة مسار المعاملة والردود والتحديثات بشكل واضح.
- توفير صلاحيات دقيقة لخمسة أدوار تشغيلية.
- تقديم لوحات تحكم، تقارير، مؤشرات أداء، وتنبيهات تلقائية.
- إنتاج مستندات قابلة للطباعة بتصميم احترافي.

## الأدوار الرئيسية
1. **Citizen** — المواطن
2. **Advisor** — المستشار
3. **Agency Officer** — موظف الجهة
4. **Follow-up Officer** — المتابع
5. **Complaint System Manager** — مدير النظام

## الوحدات الرئيسية
- **Complaint Case**: الملف الرئيسي للشكوى أو التظلم
- **Complaint Assignment**: سجل الإحالات والتكليفات
- **Complaint Update**: سجل التحديثات والتعليقات
- **Government Entity**: الجهات والهيئات الحكومية
- **Complaint Category**: تصنيفات الشكاوى وقيم SLA

## أهم المزايا
- إنشاء ملفات شكاوى وتظلمات من خلال **Web Form** عام.
- تتبع الحالة من خلال صفحة مخصصة للمواطن.
- حساب تلقائي لأوقات الاستجابة والمعالجة وفق التصنيف.
- تنبيه تلقائي للحالات المتأخرة أو القريبة من تجاوز SLA.
- **Workflow رسمي** لإدارة انتقالات الحالة بين المراجعة، الإحالة، المعالجة، الإغلاق.
- **إشعارات بريدية** للمواطن وفرق العمل عند الاستلام، الإحالة، وتحديث الحالة.
- **بوابة مواطن مبسطة** لعرض الطلبات الخاصة بالمستخدم المسجل عبر `/my-cases`.
- **خط زمني للحالة** عبر `/case-timeline` مع إمكانية إرسال ملاحظة من المواطن المسجل.
- **إعدادات إشعارات مركزية** لدعم البريد الإلكتروني وSMS وWhatsApp.
- **تكامل AI قابل للتهيئة** مع ChatGPT وDeepSeek وGemini.
- **مساعد ذكي لمستشار استقبال الشكاوى** لتحليل الحالة واقتراح التصنيف والرد والجهة.
- **تحقق من هوية مقدم الشكوى** قبل الإرسال عبر البريد الإلكتروني أو SMS أو WhatsApp أو Telegram.
- **شاشة مستقلة وجميلة للتحقق OTP** عبر `/verify-identity` مع إعادة إرسال وعدّاد زمني وسجل محاولات واضح.
- **خط رسمي موحد للتطبيق**: Droid Arabic Kufi في الواجهات والطباعة.
- **بيانات يمنية مرجعية للمحافظات والمديريات** مع ربطها بالنماذج والدوكتايب ذات الصلة.
- تقارير تنفيذية: ملخص الشكاوى، تجاوزات SLA، عبء العمل، رضا المواطنين.
- قوالب طباعة احترافية لجميع الكيانات الأساسية.
- Workspaces ولوحات معلومات حسب الدور، بالإضافة إلى **Yemen Complaints Command Center** الذي يجمع الدوكتايبات والتقارير والبطاقات والرسوم والوثائق في مساحة عمل موحدة.
- ملفات **fixtures** مرئية داخل المجلد `fixtures/` للعناصر الإدارية الأساسية.
- ملف **ترجمة عربي مبدئي** + إعدادات **CI** ومرجع **Docker** للنشر.

## دورة العمل المقترحة
1. المواطن يرسل الشكوى أو التظلم.
2. المستشار يراجع ويفرز ويحدد الجهة والتصنيف.
3. موظف الجهة يعالج الحالة ويضيف الردود.
4. المتابع يراقب الإنجاز والتأخير والتصعيد.
5. مدير النظام يراجع الأداء والتقارير والتهيئة.

## التثبيت المقترح داخل Bench
```bash
bench new-app yemen_complaints
# استبدل الملفات بالهيكل المرفق
bench --site your-site install-app yemen_complaints
bench --site your-site migrate
```
