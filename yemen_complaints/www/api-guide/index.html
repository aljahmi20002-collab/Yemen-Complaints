بوابة وثائق رسمية داخل التطبيق

دليل تكامل API

مرجع سريع لنقاط التكامل الحالية في التطبيق، خاصة التتبع والبوابة والتحقق من الهوية وأدوات الذكاء الاصطناعي.

فهرس الوثائق

1. أمثلة على الدوال المتاحة

  • yemen_complaints.api.track_case
  • yemen_complaints.api.get_my_cases
  • yemen_complaints.api.get_case_timeline
  • yemen_complaints.verification.send_identity_verification_code
  • yemen_complaints.verification.confirm_identity_verification_code
  • yemen_complaints.ai.perform_text_action
  • yemen_complaints.ai.run_intake_assistant

2. مثال تتبع حالة

{
  "method": "yemen_complaints.api.track_case",
  "args": {
    "case_id": "CMP-2026-00001",
    "email": "citizen@example.com"
  }
}

3. مثال OTP

{
  "method": "yemen_complaints.verification.send_identity_verification_code",
  "args": {
    "channel": "Email",
    "contact_value": "citizen@example.com",
    "citizen_full_name": "اسم المواطن"
  }
}

4. مثال AI Text Action

{
  "method": "yemen_complaints.ai.perform_text_action",
  "args": {
    "doctype": "Complaint Case",
    "docname": "CMP-2026-00001",
    "source_field": "details",
    "target_field": "internal_notes",
    "action_key": "summarize"
  }
}

5. ملاحظات

  • بعض الدوال تتطلب صلاحيات مستخدم داخلي.
  • بعض الدوال مفعلة للضيف مثل التحقق OTP أو التتبع المشروط.
  • يفضل اختبار كل نقطة تكامل في staging أولاً.
