دليل الاستخدام الكامل

نسخة HTML قابلة للطباعة والاستخدام اليومي للمواطن، المستشار، موظف الجهة، المتابع، ومدير النظام.

العودة إلى فهرس الوثائق فتح الوثيقة الشاملة

1. دليل المواطن

تقديم شكوى

  1. افتح الرابط /submit-complaint.
  2. أدخل البيانات الأساسية وبيانات الاتصال.
  3. اختر قناة التحقق من الهوية.
  4. أرسل رمز التحقق وأكّده.
  5. أكمل موضوع الشكوى وتفاصيلها والجهة والتصنيف.
  6. أرسل الطلب.

تقديم تظلم

  1. افتح /submit-appeal.
  2. أدخل المرجع السابق وسبب التظلم.
  3. تحقق من الهوية ثم أرسل الطلب.

المتابعة

  • من الصفحة العامة: /track-complaint
  • من البوابة: /my-cases
  • من الخط الزمني: /case-timeline

2. دليل المستشار Advisor

  1. افتح Workspace: Advisor Complaint Desk.
  2. راجع الحالات الجديدة وقيد المراجعة.
  3. افتح الحالة وراجع الموضوع والتفاصيل والمرفقات.
  4. شغّل Smart Intake Assistant عند الحاجة.
  5. راجِع التوصيات ثم طبق ما يلزم بواسطة Apply AI Recommendations.
  6. قم بالإحالة إلى المستخدم أو الجهة المناسبة.

أدوات الذكاء الاصطناعي النصية

ترجمة نص / تلخيص نص / تحسين الكتابة
إصلاح الإملاء والنحو / تبسيط اللغة / جعل النص رسمي
تحليل نص / تصنيف الموضوع / البحث عن عناصر النص
اقتراح رد / صياغة رسالة / خلاصة نص

3. دليل موظف الجهة

  1. افتح Workspace: Agency Officer Desk.
  2. ابدأ معالجة الحالة عبر In Progress.
  3. أضف التحديثات والردود.
  4. إذا احتجت بيانات من المواطن، انقل الحالة إلى Waiting Citizen.
  5. أضف Resolution Summary عند الحسم.

4. دليل موظف المتابعة

  1. افتح Workspace: Follow-up Desk.
  2. راقب الحالات المتأخرة والرسوم التحليلية.
  3. استخدم تقرير SLA Breaches.
  4. تابع التحريك أو الإغلاق حسب صلاحياتك.

5. دليل مدير النظام

إعداد الإشعارات

  • افتح Complaint Notification Settings.
  • فعّل القنوات المناسبة: Email / SMS / WhatsApp / Telegram.
  • اضبط إعدادات OTP والتحقق من الهوية.

إعداد AI

  • افتح Complaint AI Settings.
  • فعّل AI وأدخل API Key وModel وEndpoint.

السجلات المهمة

  • Complaint AI Log
  • Complaint Identity Verification
  • Error Log
  • Scheduler / Jobs

6. المشاكل الشائعة

لم يصل رمز التحقق

  • تحقق من القناة المختارة.
  • تحقق من البريد أو الرقم أو معرف تيليجرام.
  • تأكد من أن إعدادات المزود مكتملة.
  • انتظر انتهاء العدّاد ثم أعد الإرسال.

لم يعمل الذكاء الاصطناعي

  • تحقق من تفعيل AI.
  • راجع API Key وModel وEndpoint.
  • افحص Complaint AI Log.

لا تظهر لوحة العمل

  • تأكد من الدور المعطى للمستخدم.
  • نفّذ migrate وbuild.
  • تحقق من الـ fixtures أو الـ workspace definitions.

7. أفضل الممارسات

  • راجع مخرجات الذكاء الاصطناعي قبل اعتمادها.
  • لا تغلق أي حالة بدون Resolution Summary.
  • حدّث الحالة والتعليقات أولاً بأول.
  • راقب محاولات OTP للحالات غير الطبيعية.
