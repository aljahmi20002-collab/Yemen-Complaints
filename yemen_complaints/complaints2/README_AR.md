# الهيكل التنظيمي الأعلى للموديول Complaints2

هذا المجلد يقدم **تنظيماً مرجعياً عالياً** للموديول `Complaints2` بدون كسر متطلبات Frappe القياسية.

## مبدأ التنظيم
بعض المسارات في Frappe يجب أن تبقى في أماكنها الأصلية مثل:
- `doctype/`
- `report/`
- `workspace/`
- `dashboard_chart/`
- `page/`

لذلك تم اعتماد طبقة **تنظيم مرجعي** إضافية تحتوي على manifests وREADME files تربط الوظائف بالمواقع التشغيلية الفعلية.

## المجلدات التنظيمية
- `dashboards/` : تعريفات مرجعية للداشبوردات
- `portals/` : مرجع صفحات المواطن والبوابات العامة
- `docs_pages/` : مرجع صفحات التوثيق العامة وDesk pages المرتبطة بها
- `ai/` : مكونات الذكاء الاصطناعي
- `security/` : مكونات الأمن والحماية وسجلات abuse protection
- `reference_data/` : البيانات المرجعية اليمنية وغيرها
- `reporting/` : التقارير والرسوم والبطاقات
- `workspaces_index/` : فهرس Workspaces ومحتوياتها التشغيلية
- `taxonomy/` : خرائط تنظيمية وملفات manifest شاملة
